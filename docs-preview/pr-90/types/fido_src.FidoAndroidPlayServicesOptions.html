    Type Alias FidoAndroidPlayServicesOptions

    Play Services request overrides for Android FIDO authentication.

    Remarks

    Applied natively to the PublicKeyCredentialRequestOptions the Android SDK builds for the authentication ceremony. A field left unset keeps the native value. The block is applied only when the selected route is Play Services and the Play Services FIDO API is available; otherwise it is not applied and a warning is logged. Android only: on iOS the whole android block is removed from the native configuration before the call.

    The host app must declare com.google.android.gms:play-services-fido; the package declares it compileOnly, so it is not bundled transitively. Without it native auto-detection selects Credential Manager and a supplied playServices block is not applied and a warning is logged. useFido2ApiClient: true does not make the block apply without it.

    Example

    const ceremonyOptions = {
      android: {
        useFido2ApiClient: true,
        playServices: {
          timeoutSeconds: 60,
          transports: ['usb', 'nfc', 'ble'],
        },
      },
    };

        };

    Optionaltransports

    transports?: string[]

    WebAuthn transport names, for example usb, nfc or ble, applied to every credential of the allow list.

    Remarks

    One flat list for all descriptors; there is no per-credential transport selection. Transport names are forwarded to native unchanged: native drops unsupported names with a warning, so no JavaScript-side name allowlist is applied.
