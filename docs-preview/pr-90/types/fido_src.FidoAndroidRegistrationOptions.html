    Type Alias FidoAndroidRegistrationOptions

    Credential Manager create-request overrides for Android FIDO registration.

    Remarks

    Applied natively to the CreatePublicKeyCredentialRequest the Android SDK builds for the registration ceremony. A field left unset keeps the native value. Android only: on iOS the whole android block is removed from the native configuration before the call.

    Example

    const ceremonyOptions = {
      android: {
        credentialManager: {
          preferImmediatelyAvailableCredentials: true,
          preferDefaultProvider: 'com.example.auth/.PasskeyProvider',
        },
      },
    };
