    Type Alias DaVinciMetadataResult

    DaVinciMetadataResult: Record<string, unknown>

    Success result for a MetadataCollector — the exact object applied to the native collector and POSTed as formData.sdkMetadata when the flow resumes.

    Remarks

    Must be a plain JSON object, forwarded to the native collector unchanged (an empty object is not special-cased). An object carrying an error key is interpreted as a DaVinciMetadataErrorResult instead — build that shape with buildMetadataError.

    Platform difference in native 2.2.0: iOS posts an empty result as formData.sdkMetadata: {}, which the server accepts. Android omits an empty result from the resume request, and the server replies with an INVALID_RESUME_PAYLOAD message instead of resuming. Return a non-empty object on Android until the native SDK is fixed.
